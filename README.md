 Sales Performance Analysis (Python, SQL, Power BI)

 Overview
This project focuses on understanding key sales patterns, customer behavior, discount impact, and subscription effectiveness. Using SQL, Python, and Power BI, business questions were explored to support data-driven insights.

---

 Tech Stack
SQL (MySQL Workbench)
Python (Jupyter Notebook)
Power BI (Dashboard & Visual Insights)

---

 Project Files
| Folder / File | Purpose |
|---------------|---------|
| `data/` | Contains the dataset used for analysis |
| `sql/sales_analysis_queries.sql` | Full set of SQL queries used to extract insights |
| `notebooks/` | Python notebook for cleaning and analysis |
| `powerbi/` | Power BI dashboard file (`.pbix`) and visuals |
| `README.md` | Project explanation document |

---

 Key Business Questions Answered
1. How do spending patterns vary by customer type and demographics?
2. Do discount users spend more or less overall?
3. Which products receive highest ratings and purchase frequency?
4. Do subscribers contribute more revenue vs non-subscribers?
5. How do shipping choices affect purchase amount?
6. Which products are most influenced by discounts?
7. Customer segmentation by purchase frequency (New, Returning, Loyal).
8. Top 3 most purchased products within each category.
9. Are repeat buyers also subscription-driven?
10. Age-wise revenue contribution.

---

 Dashboard
A Power BI interactive dashboard has been created to visualize:
- Which customer segments spend the most
- Which product categories generate the highest revenue and sales
- Subscription distribution
- Review score performance
- Impact of age group on revenue trends
